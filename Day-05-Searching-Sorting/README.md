# Day 5 — Searching & Sorting

## Learning Goals
- Understand searching and sorting
- Implement Linear Search
- Implement Binary Search
- Understand when Binary Search can be used
- Implement Bubble Sort
- Implement Selection Sort
- Implement Insertion Sort
- Compare time complexities

## Topics
1. Linear Search — O(n)
2. Binary Search — O(log n), requires sorted data
3. Bubble Sort — O(n²) average/worst
4. Selection Sort — O(n²)
5. Insertion Sort — O(n²) average/worst, O(n) best

## Run
```bash
python implementation.py
python practice.py
```

## Key Rule
Binary Search works correctly only when the data is sorted (or when the search space has an appropriate monotonic order).
