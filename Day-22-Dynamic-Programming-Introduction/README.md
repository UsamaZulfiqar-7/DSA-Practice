# Day 22 — Dynamic Programming (DP) Introduction

A beginner-friendly Python project introducing Dynamic Programming through Fibonacci and Climbing Stairs.

## Topics
- Overlapping subproblems and optimal substructure
- Recursion vs Dynamic Programming
- Memoization (top-down)
- Tabulation (bottom-up)
- Fibonacci and Climbing Stairs
- Time and space complexity

## Files
- `notes.md` — theory and complexity notes
- `implementation.py` — reusable implementations
- `practice.py` — 12 exercises
- `solutions.py` — worked solutions and self-tests

## Run
```powershell
python implementation.py
python solutions.py
python practice.py
```

Only Python's standard library is required.
