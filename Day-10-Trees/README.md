# Day 10 — Trees

Trees are non-linear hierarchical data structures.

## Core concepts
- Root, parent, child, leaf, edge
- Binary Tree
- DFS: Preorder, Inorder, Postorder
- BFS: Level Order
- Height, depth, node count
- Binary Search Tree (BST)
- BST search and minimum

## Traversals
- Preorder: Root → Left → Right
- Inorder: Left → Root → Right
- Postorder: Left → Right → Root
- Level Order: level by level using a queue

## Complexity
| Operation | Complexity |
|---|---:|
| DFS traversal | O(n) |
| BFS traversal | O(n) |
| Binary Tree search | O(n) |
| Height | O(n) |
| Balanced BST search | O(log n) average |
| Skewed BST search | O(n) |
