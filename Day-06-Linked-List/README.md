# Day 6 — Linked List

A Linked List is a linear data structure made of nodes. Each node stores data and a reference to the next node.

## Topics
- Node and Head
- Singly Linked List
- Traversal
- Insert at beginning/end/position
- Delete by value
- Search and length
- Reverse a linked list
- Slow/Fast pointers
- Cycle detection

## Complexity
| Operation | Singly Linked List |
|---|---:|
| Access by index | O(n) |
| Search | O(n) |
| Insert at beginning | O(1) |
| Insert at end* | O(n) |
| Delete by value | O(n) |
| Traverse | O(n) |
| Reverse | O(n) |

*Without a tail pointer.
