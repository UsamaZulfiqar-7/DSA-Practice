# Day 12 — Heap & Priority Queue ⛰️

## Learning goals
- Understand min-heaps and max-heaps.
- Use Python's `heapq` module.
- Implement a priority queue.
- Practice top-K and Kth-largest/smallest patterns.

## Key idea
A heap is a complete binary tree that keeps its highest-priority element at the root. A min-heap has the smallest value at the root; Python `heapq` is a min-heap by default. A heap is not a fully sorted list.
