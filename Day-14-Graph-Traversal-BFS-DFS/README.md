# Day 14 — Graph Traversal: BFS & DFS 🕸️

## Learning goals
- Traverse graphs with Breadth-First Search (BFS) and Depth-First Search (DFS).
- Use visited sets to prevent repeated visits and cycles.
- Understand queue vs stack/recursion.
- Find shortest paths in unweighted graphs using BFS.
- Handle disconnected graphs.
