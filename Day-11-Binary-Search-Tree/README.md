# Day 11 — Binary Search Tree (BST) Deep Dive 🌲

## Learning goals
- Understand the BST property.
- Implement insert, search, minimum/maximum, and deletion.
- Validate a BST using inherited bounds.
- Understand inorder successor and complexity.

## BST rule
For each node, every value in the left subtree is smaller and every value in the right subtree is greater. This project uses unique integer values; duplicate insertions are ignored.

## Files
- `notes.md`: theory and complexity
- `implementation.py`: reusable BST class
- `practice.py`: exercises
- `solutions.py`: reference solutions

## Run
```bash
python implementation.py
python solutions.py
```
