# Day 24 — LCS & LIS

A Python project covering two classic Dynamic Programming problems: Longest Common Subsequence (LCS) and Longest Increasing Subsequence (LIS).

## Run
```bash
python implementation.py
python solutions.py
python practice.py
```
No external packages required (Python 3.8+).

## Files
- `notes.md`: concepts, recurrence relations and complexity
- `implementation.py`: reusable algorithms
- `practice.py`: 12 exercises
- `solutions.py`: worked examples and tests
