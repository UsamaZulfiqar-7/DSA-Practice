# Day 21 — Greedy Algorithms

A beginner-friendly Python project covering common greedy algorithm patterns.

## Topics
- What makes an algorithm greedy
- Activity selection / interval scheduling
- Fractional knapsack
- Minimum number of coins (for canonical coin systems; not guaranteed optimal for every denomination system)
- Greedy strategy: sorting, choosing locally optimal options, and proving correctness

## Files
- `notes.md` — concepts, examples, complexity, and pitfalls
- `implementation.py` — reusable implementations
- `practice.py` — 12 exercises
- `solutions.py` — sample solutions and assertions

## Run
```bash
python implementation.py
python solutions.py
python practice.py
```

No third-party packages required.
