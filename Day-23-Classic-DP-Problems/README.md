# Day 23 — Classic Dynamic Programming Problems

This project covers three classic DP patterns:

1. **0/1 Knapsack** — choose each item at most once to maximize value within a capacity.
2. **Coin Change** — minimum number of coins needed to make an amount (unlimited coins).
3. **House Robber** — maximize the amount robbed without choosing adjacent houses.

## Files
- `notes.md`: concepts, recurrences, complexity, and common mistakes.
- `implementation.py`: clear implementations, including reconstruction for 0/1 Knapsack.
- `practice.py`: 12 exercises.
- `solutions.py`: worked examples and automated tests.

## Run (Python 3.9+)
```powershell
python implementation.py
python solutions.py
python practice.py
```

No third-party packages are required.
